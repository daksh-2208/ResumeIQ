# ResumeIQ By Daksh

ResumeIQ is an AI-powered Resume ATS Analyzer built using Flask, NLP, and Machine Learning concepts. It analyzes resumes against job descriptions, calculates ATS scores, detects technical skills, identifies missing skills, evaluates project relevance, and recommends suitable tech roles like Backend Developer, AI/ML Engineer, Data Analyst, and Frontend Developer.

---

## Features

- ATS Score Calculation  
- Resume vs Job Description Matching  
- Skill Detection & Gap Analysis  
- AI-Based Role Recommendation  
- Project Relevance Analysis  
- PDF Resume Parsing  
- Backend + AI/ML Intelligent Analysis  
- Interactive UI Dashboard
